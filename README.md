# instagram_reach_analyser
A small data analysis project using Pandas to study Instagram post performance.
->Loads post analytics data (likes, comments, shares, saves, impressions, reach).
->Calculates save rate, follow rate, explore share, and engagement.
->Tags captions into hook types (question, number, contrarian, story, how‑to).
->Compares average performance by hook type and flags viral posts.
->Exports top captions by save rate for quick reference.
